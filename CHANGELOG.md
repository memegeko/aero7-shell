# Changelog

## 1.0.0 - 2026-08-14

- Declared Aero7-shell feature-complete and moved the project to maintenance.
- Established `release` as the canonical stable branch.
- Finalized the resumable installer, signed package integration, Plasma 6
  Wayland configuration, Aero application branding, SDDM, Plymouth, Fastfetch,
  backup, recovery, repair, and uninstall paths.
- Removed obsolete platform-specific testing guides while retaining the full
  automated validation suite and hardware-safe guards.
- Updated public installation instructions to use checksum-verified release
  archives.

## 0.1.0

- Initial modular Aero7-shell project scaffold.
- Added checksum-verifying bootstrapper, staged installer, state, logging, backup, package, AUR, bootloader, initramfs, app recipe, and management command framework.
- Added Windows-like compatibility commands, Fastfetch profile, Wine integration hooks, docs, tests, and CI.
